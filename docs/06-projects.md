# Проекты сообщества

От чего можно оттолкнуться вместо написания с нуля. Все проекты работают на HUB75 и ESP32,
большинство на той же библиотеке DMA.

## Готовые прошивки под ключ

### hub75-studio
[pavlov-net/hub75-studio](https://github.com/pavlov-net/hub75-studio) · MIT · 24 звезды ·
последний релиз v0.7.1 от 2026-04-19

ESPHome плюс LVGL. Самый близкий к нашему железу проект: пакет контроллера Waveshare уже
написан, хотя готового бинаря нет.

Страницы: обложки альбомов с информацией о треке, спортивные табло через ha-teamtracker,
часы с погодой, аудиоспектр в реальном времени, радар присутствия для MSR-2, таймеры
обратного отсчёта, QR-коды, Pong, эффекты (фейерверк, камин, полярное сияние), стриминг
GIF и видео с YouTube через media-proxy.

Отдельные компоненты, которые можно взять по частям:
`lvgl-ddp-stream`, `lvgl-canvas-fx`, `lvgl-page-manager`.

### WLED
[wled/WLED](https://github.com/wled/WLED) · EUPL-1.2

Официальная сборка под нашу плату есть. Больше двухсот эффектов, веб-интерфейс,
JSON API, приложения для iOS и Android, интеграция с Home Assistant из коробки.
Начиная с версии 16 в составе идёт Pixel Forge: конвертация изображений в GIF прямо
на устройстве, редактор бегущей строки с подстановкой времени и температуры, попиксельный
редактор Pixel Paint с превью на самой панели.

### Tronbyt
[tronbyt/server](https://github.com/tronbyt/server) · 197 звёзд

Локальная замена облачному сервису Tidbyt после того, как компанию купили и слияния
пул-реквестов прекратились. Приложения пишутся на Starlark через
[pixlet](https://github.com/tronbyt/pixlet), рендерятся в WebP и отправляются на
устройство. Каталог приложений сообщества — [tronbyt/apps](https://github.com/tronbyt/apps).
Есть интеграция с Home Assistant: `tronbyt/TronbytAssistant`.

Поддерживаемое железо включает MatrixPortal S3 и Raspberry Pi с панелями. Прошивка
[tronbyt/firmware-esp32](https://github.com/tronbyt/firmware-esp32) с версии 1.5.0
использует библиотеку `esp-hub75`, ту же, что лежит под компонентом ESPHome.

Модель работы: сервер генерирует картинку, устройство её показывает. Без сервера
устройство не обновляется.

## Проекты-часы и информационные панели

### DigiFrame
[manoharc07/DigiFrame](https://github.com/manoharc07/DigiFrame)

Ближе всего к нашему железу по постановке: 64x64, ESP32-S3 N16R8, панель Waveshare
P2.5 64x64. Часы по NTP, погода через Open-Meteo без ключа API, живая фоновая сцена,
GIF по кругу, бегущие строки, тематические поздравления по датам.

Четыре способа управления: облачная статическая страница через Web Bluetooth, собственный
веб-дашборд на устройстве, телеграм-бот, Home Assistant через MQTT с автообнаружением.

Архитектурно интересен разделением по ядрам: ядро 1 владеет панелью, декодером GIF и
веб-сервером, ядро 0 крутит телеграм, погоду и MQTT, а общий слой `control.h` держит по
одной реализации на действие, чтобы все интерфейсы вели себя одинаково. Задачи с ядра 0
передают работу на ядро 1 через очередь команд и никогда не трогают панель напрямую.

Хороший образец для подражания, если будем писать своё.

### esp32-morphing-clock
[bogd/esp32-morphing-clock](https://github.com/bogd/esp32-morphing-clock) · GPL-3.0

Часы с перетекающими цифрами. Дата, время, день недели, наружная температура через MQTT,
датчик освещённости TSL2591 для автояркости, прогноз погоды на пять дней, OTA по команде
из MQTT, сторожевой таймер для автоперезапуска. В комплекте схема платы расширения и
чертежи корпуса из оргстекла под лазерную резку.

### FamilyClock
[goguelnikov/FamilyClock](https://github.com/goguelnikov/FamilyClock) · GPL-3.0

Семейные часы на 64x32. Семь экранов: часы, погода, ближайшее событие, расписание дня,
фаза луны, заметки, дни рождения. Полная настройка через веб-интерфейс, семь вкладок,
девять цветовых тем, REST API, регулировка яркости в реальном времени.

Ценен структурой кода: отдельные сервисы для NTP, погоды и календаря, отдельный класс на
каждый экран, менеджер ротации экранов.

### HUB75-Pixel-Art-Display
[mzashh/HUB75-Pixel-Art-Display](https://github.com/mzashh/HUB75-Pixel-Art-Display)

Проигрыватель пиксель-арта. GIF из флеша, NTP-часы, бегущая строка, веб-интерфейс с
загрузкой и удалением файлов, авторизацией и удалённой перезагрузкой. По умолчанию
настроен ровно на панель 64x64 с развёрткой 1/32, то есть на нашу.

### matrix-display
[aslak3/matrix-display](https://github.com/aslak3/matrix-display)

Панель данных Home Assistant через MQTT с автообнаружением. Интересен переносимостью:
одна кодовая база собирается под RP2040, RP2350 и ESP32, конфигурация платы вынесена в
cmake-файлы. Данные не вытягиваются устройством, а проталкиваются автоматизациями HA,
что даёт больше гибкости.

## Смежная экосистема

Работают на других типах матриц, но идеи и протоколы переносимы.

| Проект | Железо | Чем интересен |
|---|---|---|
| [AWTRIX 3](https://github.com/Blueforcer/awtrix3) | Ulanzi TC001, 32x8 | эталон интеграции с HA через MQTT: приложения как топики, JSON-полезная нагрузка, автоматическая ротация, иконки из галереи LaMetric |
| [PixelIt](https://github.com/pixelit-project/PixelIt) | ESP8266/ESP32, WS2812B | JSON API, узел для Node-RED, адаптер ioBroker, автообнаружение в HA |
| [Pixelix](https://github.com/BlueAndi/Pixelix) | ESP32, WS2812B и TFT | плагинная архитектура, REST и MQTT API, ограниченная поддержка HUB75 |

Модель AWTRIX стоит изучить отдельно: каждое «приложение» — это отдельный MQTT-топик
вида `awtrix/custom/имя`, куда публикуется JSON с текстом, иконкой и длительностью.
Устройство само крутит их по кругу. Пустая полезная нагрузка убирает приложение.
Простая и очень удобная схема, которую легко воспроизвести на своём железе.

## Идеи под наше железо

Периферия, которой нет у Apollo, открывает то, чего в перечисленных проектах нет:

- **Голосовой ассистент.** Два микрофона, эхоподавление ES7210 и динамик на борту.
  В пакете hub75-studio для нашей платы уже настроены `micro_wake_word` со словом
  активации и `voice_assistant`.
- **Реакция на движение.** IMU QMI8658 даёт наклон и встряхивание как способ управления
  без кнопок, плюс физические эффекты типа падающего песка.
- **Автономные часы.** RTC PCF85063 с батарейкой держит время без сети.
- **Локальный климат.** SHTC3 показывает температуру и влажность прямо у панели, без
  внешних датчиков.
- **Автономный плеер.** Слот TF-карты позволяет крутить GIF без Wi-Fi и без сервера.
