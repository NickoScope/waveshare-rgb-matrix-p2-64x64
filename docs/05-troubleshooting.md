# Диагностика: симптом → причина → лечение

Таблица собрана из issue #134 библиотеки ESP32-HUB75-MatrixPanel-DMA (официальный
сборник типовых проблем), руководства по устранению неполадок esp-hub75 и документации
компонента ESPHome.

## Общая таблица

| Симптом | Вероятная причина | Что делать |
|---|---|---|
| Чёрный экран | не тот драйверный чип | попробовать `shift_driver: FM6126A`. Для нашей панели штатное значение GENERIC, так что сначала проверить питание и шлейф |
| Чёрный экран на 64 строках | не задан пин E | панель 1/32 scan, E обязателен |
| Гостинг, дубли со сдвигом по горизонтали | панель не успевает за скоростью библиотеки | `latch_blanking` до 4, тактовая до 10 или 8 МГц, яркость до 128, шлейф короче |
| Пиксели смещены на один, столбец x=0 не виден | фаза тактового сигнала | `clkphase = false` (в ESPHome `clock_phase`) |
| Размытая картинка | фаза тактового сигнала, обратный случай | `clkphase = true` |
| Мерцание, мусор на экране | слабый или нестабильный блок питания | блок с запасом, ровно 5 В, конденсатор 1000 мкФ на входе питания панели |
| Мерцание при исправном питании | разные земли | соединить землю блока и землю платы |
| Половина экрана в цвете, вторая тёмная | размер панели задан 32x32 вместо 64x64 | исправить конфигурацию |
| Чересстрочные полосы, двоение | выбран вариант с четвертной развёрткой | вернуть Standard / half scan |
| Цвета не те | перепутаны линии RGB | проверить R1/G1/B1 и R2/G2/B2. Встречаются партии панелей с заводской ошибкой в разводке R2/G2 |
| Часть строк не светится | GPIO не выдаёт 3.3 В | измерить тестером, при меньшем напряжении плата дефектная |
| Экран погас после смены настроек HUB75 | так работает WLED | перезагрузить устройство, это ожидаемое поведение |
| Мусор ровно на половине одной панели | брак панели | вернуть продавцу, программного лечения нет |
| Wi-Fi плохо работает при активной панели | наводки от DMA на радиотракт | известная проблема класса ESP32-S3, см. 04-best-practices |
| Порт не определяется при прошивке | плата не в режиме загрузки | зажать BOOT, подключить USB, отпустить BOOT, после заливки нажать RESET |
| Цвета блёклые, пастельные | изменена продвинутая настройка HUB75 | сброс к заводским настройкам |

## Порядок отладки при незаводящейся панели

Из руководства esp-hub75, проверять по списку:

1. Блок питания 5 В подключён к панели, ток достаточный (3–5 А на панель 64x64)
2. Земля ESP32 соединена с землёй блока питания
3. Выбран верный пресет платы или вручную заданы все пины
4. Размеры панели в конфигурации совпадают с физическими, включая тип развёртки
5. Прошивка действительно залилась
6. В мониторе порта видно успешную инициализацию драйвера

Рекомендованная стратегия: начать с `GENERIC` и `STANDARD`, добиться хоть какой-то
картинки, пусть с неверными цветами, и только потом крутить драйвер и развёртку.

## Соответствие высоты панели и развёртки

| Высота панели | Развёртка |
|---|---|
| 16 px | 1/8 |
| 32 px | 1/16 |
| **64 px** | **1/32** |

Наша панель — 64 строки, 1/32, пин E обязателен.

## Что собрать перед обращением за помощью

Из шаблона esp-hub75:

- вариант ESP32 (у нас S3)
- модель платы (ESP32-S3-RGB-Matrix)
- размер и модель панели (RGB-Matrix-P2-64x64-B)
- количество панелей
- пресет платы или карта пинов
- настройки панели: размеры, развёртка, битность
- раскладка при нескольких панелях
- значение shift driver
