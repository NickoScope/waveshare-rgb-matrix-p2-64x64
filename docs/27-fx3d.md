## Design

**One scene, one or two cameras, one compositor.**

1. *Scene*: real 3D coordinates and a time. Both eyes see the same scene state.
2. *Projection*: mono, or off-axis stereo - parallel cameras at x = ±b/2 and a
   zero-parallax plane at Z0 (the brief §4). No toe-in.
3. *Raster*: into **linear-light** buffers - points splatted at sub-pixel
   positions, anti-aliased lines, triangles with a z-buffer.
4. *Compose*: mono colour, or anaglyph (red-blue first, red-cyan, red-green),
   with per-channel gains and an eye swap. Additive, so one eye never erases
   the other.
5. *Encode once*: linear light → the CIE lightness the library expects, through
   a table that inverts the library's own. No double gamma.
6. *Blit*: 128×64 RGB888 from PSRAM, like the Lua effects.

The arithmetic lives in plain-C++ headers under `src/fx3d/`, tested on the Mac
by `tools/fx3d/check_fx3d.py`. The same code renders the previews, so a
preview is the firmware's own output.

**Depth budget.** The disparity of a point at depth Z is
d = f·b·(1/Z − 1/Z0) pixels. The scene declares its depth range and the
baseline b is chosen so that |d| stays within a setting that starts at 1-2 px
(the brief §4: an experiment setting, not a norm). Vertices are never clamped
one by one.

## Decisions taken

| Date | Decision | Why |
|---|---|---|
| 2026-09-18 | Previews first, rendered by the firmware's own code; the owner picks | the owner's answer |
| 2026-09-18 | Anaglyph is an output mode of the same scenes, not a separate project | the brief wants real 3D coordinates; the hardware is already known; the worktree's rules put the work in `src/fx3d/` |
| 2026-09-18 | `float` only, never `double` | single-precision FPU, `double` emulated |
| 2026-09-18 | Linear light inside, the CIE encode once at the end | the library applies CIE 1931 to every pixel |
| 2026-09-18 | Off-axis stereo with a zero-parallax plane, no toe-in | the brief §4 |
| 2026-09-18 | Disparity is limited through the baseline, never by clamping vertices | the brief §4 |
| 2026-09-18 | Red-blue first; red-cyan only once green has been checked through the filters | the brief §7 |

  if a scene the owner picks needs it: a stack is internal RAM.

  alone, like the Lua effects), then the clock style, ambient, and music.
